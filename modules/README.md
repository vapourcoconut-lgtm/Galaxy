# 工作台模块与子模块

## 1. 总控制台

用途：汇总目标、任务、进度、截止日期和风险，帮助做取舍。

子模块：

- 年度目标与阶段目标
- 本月重点、本周重点、今日任务
- 模块进度
- 截止日期
- 待确认事项
- 风险与问题
- 最近完成事项
- 下一步行动

## 2. 雅思学习

用途：管理训练计划、结果、错因和阶段进度，是当前最高优先级模块。

子模块：

- 阅读
- 听力
- 写作 Task 1 / Task 2
- 口语 Part 1 / Part 2 / Part 3
- 词汇与表达
- 错题和问题
- 模考
- 每日计划
- 学习复盘
- 分数预测与趋势

## 3. 研究生申请与职业探索

用途：逐步比较项目、准备材料和验证职业方向，不提前替用户做唯一决定。

子模块：

- 院校和专业
- 申请要求与时间线
- 背景提升
- 简历、PS、推荐信
- 成绩单和证明材料
- 申请状态
- 专业方向对比
- 职业方向分析

## 4. 大四学业与毕业论文

用途：管理课程、作业、考试和论文。当前只建目录，计划于 2026 年 10 月起启用。

子模块：

- 课程列表和时间表
- 作业、考试和复习
- 高级经济学知识
- 毕业论文选题
- 文献阅读
- 数据和研究方法
- 导师反馈
- 截止日期

## 5. 运动与健康习惯

用途：保持可持续运动，观察运动、疲劳、恢复与学习状态的关系。

子模块：

- 跑步机爬坡
- 背部训练
- 拉伸和恢复
- 身体感受
- 周度趋势

## 6. 阅读计划

用途：管理书单、阅读进度、笔记和年度总结，并控制额外负担。

子模块：

- 年度和月度目标
- 想读、在读和已读
- 阅读记录
- 阅读笔记
- 读后感
- 年度总结

## 7. 个人事务与每日记录

用途：管理零散事项，并用真实日记支持每周和每月成长分析。

子模块：

- 备忘和临时任务
- 购买、回复、证件、预约、缴费
- 学校行政事务
- 每日日记
- 每周成长分析
- 每月成长分析
