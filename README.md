# 个人成长型 AI 工作台

这是一个可直接部署为手机网页的静态 Web App，支持响应式布局、添加到主屏幕、离线打开，以及通过 Supabase 邮箱账号在手机、电脑和平板之间同步。

## 雅思口语知识库

雅思页面现包含“学习记录”和“口语知识库”两个标签。口语知识库已支持：

- Part 1 / Part 2 / Part 3 独立分类
- Topic 创建与问题录入
- 单一 Answer 答案区，以及支持逐个新增、删除和星标重点的关键词标签
- Part 2 故事素材、关键词与相关 Part 3 问题
- Part 3 观点与支撑案例
- 红、蓝、灰三色文本高亮，以及加粗和下划线
- 标签、备注、搜索和复习状态
- 手机端响应式使用

详细关系型数据库设计见 [docs/database-design.md](docs/database-design.md)。

当前网页仍是纯前端静态版本。未登录时数据保存在浏览器本地；完成 Supabase 配置并登录后，可在不同设备间同步。

阅读模块的 2026 年默认目标为 6 本书、60 小时，按雅思学习和研究生申请优先的现实节奏设置，
用户可在“年度目标”中自行调整。摘抄图片会保存在浏览器本地，建议使用小于 1 MB 的图片。

## 在线使用

手机和电脑均可打开：

`https://vapourcoconut-lgtm.github.io/Galaxy/`

页面刷新不会丢失数据，也支持导入和导出。云端初始化步骤见
[Supabase 云同步配置](docs/Supabase云同步配置.md)。完成配置并发布后，手机和电脑登录同一邮箱账号即可同步。
